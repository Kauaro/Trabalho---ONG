## Publicar na Vercel

1. Suba esta pasta para um repositório GitHub.
2. Importe o repositório na Vercel.
3. Framework: **Vite**; comando de build: `npm run build`; diretório de saída: `dist`.
4. Publique e teste no celular.

## Antes de colocar no ar

- Obter autorização da ONG para usar o logotipo, fotografias e informações.
- **Especialmente importante:** confirmar autorização dos responsáveis legais para divulgação de imagens de menores, e verificar as regras aplicáveis da LGPD e do ECA.
- Confirmar se o número de WhatsApp continua sendo o canal institucional e se o endereço permanece correto.
- Confirmar a disponibilidade atual de inscrições, horários e faixa etária (não anunciados como atuais no site).
- Verificar dados institucionais oficiais antes de adicionar CNPJ, Pix, fundação ou números de impacto.
- Substituir imagens por arquivos originais em melhor resolução, quando disponíveis.
